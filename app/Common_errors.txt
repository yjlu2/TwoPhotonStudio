TwoPhoton Studio - common error reference

Warning: fix inputs/settings and retry. Error: the current step failed.
Full tracebacks are saved in diagnostic logs, not displayed in popups.

Warning [OUT-01] Output location cannot be used
Reason: The selected output cannot be used safely for this session copy.
Next: Choose a new folder outside the current session. The original session is retained; check the log for copy details.

Warning [DROP-01] Unsupported dropped item
Reason: The dropped item is not one saved session or a supported TIFF import.
Next: Drop a session.npy file by itself, a session folder, or single-FOV TIFF files/folders.

Error [GPU-01] GPU memory exhausted
Reason: The GPU could not allocate memory for this step.
Next: Close other GPU jobs. Retry with smaller batches or use CPU.

Error [GPU-02] GPU architecture unsupported
Reason: The installed PyTorch build does not support this GPU.
Next: Use Suite2p CPU or install a matching PyTorch/CUDA runtime.

Error [GPU-03] GPU unavailable
Reason: CUDA or the NVIDIA driver is unavailable in the selected Python environment.
Next: Check the driver and Python runtime in Settings, or choose CPU.

Error [IO-01] Disk space exhausted
Reason: An output, temporary or cache disk has insufficient free space.
Next: Free space on the affected disk or choose a different output folder.

Error [MEM-01] Memory allocation failed
Reason: The system or a model could not allocate memory; this message does not identify a specific device.
Next: Close memory-heavy programs. Check RAM, GPU memory and Windows paging-file space before retrying.

Error [IO-02] File is in use
Reason: Another process is locking a required file.
Next: Close the file in MATLAB, ImageJ or other programs, then retry.

Error [IO-03] Access denied
Reason: The file or folder is not writable, or an application is locking it.
Next: Check folder permissions and close open output files; choose a writable local folder if needed.

Error [IO-04] Path unavailable
Reason: An input file, output folder, mapped drive or runtime cannot be found.
Next: Reconnect the drive or correct the path in Sources or Settings. See the log for the exact path.

Warning [IO-05] Output already exists
Reason: The selected output filename already exists.
Next: Choose another name or use Replace where available.

Error [TIFF-01] Unsupported TIFF layout
Reason: The file is not a supported single-channel 2D frame stack.
Next: Import a 16-bit integer or 32-bit integer/float grayscale TIFF; separate channels and planes first.

Error [TIFF-02] Stack sizes differ
Reason: The imported stacks do not share the same image dimensions or FOV.
Next: Select stacks from the same FOV, plane and channel, with matching dimensions.

Warning [TIFF-03] Too few imaging frames
Reason: There are too few frames, or too few usable frames after temporal binning.
Next: Check the imported frame count. Import the complete movie; use Already registered for a registered movie.

Error [TIFF-04] Source changed
Reason: A source or registered movie no longer matches its recorded frame mapping.
Next: Restore the original file or create a new import. Do not reuse old traces with a changed movie.

Error [REG-01] No common registration area
Reason: Motion leaves no valid area shared by the registered frames.
Next: Inspect motion and registration settings; exclude corrupted input frames before rerunning.

Warning [ROI-01] ROI outside analysis area
Reason: The ROI crosses the current valid registration boundary.
Next: Move the ROI inside the yellow border or review Edit area before changing the boundary.

Error [ROI-02] Overlapping or invalid ROI masks
Reason: The masks contain duplicates, full overlap or invalid weights.
Next: Remove duplicate or empty ROIs, then recompute traces.

Error [ROI-03] Insufficient neuropil pixels
Reason: The current masks and valid area leave too few pixels for neuropil extraction.
Next: Inspect dense ROIs and valid area, or reduce the minimum neuropil pixels in Settings.

Error [SYNC-01] Frame TTL count mismatch
Reason: The synchronization frame count does not match the imaging movie.
Next: Check the MAT variable, frame column, NI sample rate and TIFF selection. Use first-rise alignment only if its assumptions hold.

Error [SYNC-02] Frame timing mismatch
Reason: Frame times do not agree with the imaging frame rate or are not increasing.
Next: Correct fs and synchronization settings, then import the MAT file again.

Error [SYNC-03] Invalid synchronization channels
Reason: The selected MAT matrix or TTL column is missing, constant or invalid.
Next: Check matrix name, 1-based column numbers and NI sample rate in Settings.

Warning [SYNC-04] Synchronization not ready
Reason: The trial analysis has no complete stimulus intervals aligned to imaging.
Next: Import the matching synchronization MAT; check trial windows and stimulus columns.

Error [MODEL-01] PROFILE configuration unavailable
Reason: A PROFILE config, matching checkpoint or inference environment is missing or incompatible.
Next: Choose the matching 2D JSON and checkpoint and check the PROFILE paths in Settings.

Error [MODEL-02] Model weights incompatible
Reason: The checkpoint is unavailable or does not match the selected model.
Next: Select matching official weights and model settings; check the checkpoint path in the log.

Error [ENV-01] Python dependency unavailable
Reason: The selected environment is missing a library or contains incompatible packages.
Next: Check the Python environment paths in Settings; repair the affected environment.

Error [FIG-01] MATLAB export unavailable
Reason: The editable FIG exporter could not find or start its MATLAB dependency.
Next: Check the MATLAB path in Settings, or export MAT/PNG/PDF instead.

Warning [SRC-01] No new TIFF stacks selected
Reason: The selection contains no new stacks or would change the existing source order.
Next: Choose new stacks from the same FOV and append them after the existing files.

Error [MAT-01] Unsupported MAT metadata
Reason: A result metadata field cannot be written to this MAT format.
Next: Save the session and retain the diagnostic log for an exporter compatibility fix.

Error [DATA-01] Invalid pixel or signal values
Reason: The source contains nonfinite values, no intensity variation or inconsistent signal dimensions.
Next: Inspect the source movie and signal arrays. Correct invalid input before analysis.

Warning [FLOW-01] Traces need recomputing
Reason: The selected ROI set or trace results are not ready for this action.
Next: Select valid cell ROIs and run Compute traces for the current ROI set.

Warning [FLOW-02] Registration not ready
Reason: A required earlier step is incomplete, or its settings have changed.
Next: Finish or stop the active operation, then rerun the required pipeline step.

Error [OTHER-01] Step failed
Use Open log for unclassified failures.
