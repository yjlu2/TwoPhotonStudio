First public **Conda source edition** of TwoPhoton Studio, based on the Studio 1.3.4 workflow.

- Windows GUI for multi-stack, single-FOV calcium imaging.
- Suite2p CPU/GPU registration and extraction; Suite2p, Cellpose-SAM and PROFILE ROI detection.
- Optional SUPPORT denoising, manual ROI review, synchronization MAT import and trial-response heatmaps.
- Fall.mat and MATLAB FIG export using an existing MATLAB installation.
- Isolated Conda environments, constrained dependencies and verified model downloads.

Download and extract the complete source ZIP, open Anaconda Prompt in the extracted folder, then run:

```bat
python install.py --device cuda
```

Use `--device cpu` without a supported NVIDIA GPU. After `INSTALLATION COMPLETE`, launch `Launch.cmd`.

The attached ZIP contains source and bundled PROFILE/SUPPORT assets, not installed environments or
experimental data. The installer downloads the Cellpose-SAM weights and Python dependencies.
MATLAB is assumed to be installed; no MATLAB Runtime installer is included.

Validated with new Windows environments and an RTX 4060. Tests cover core processing, GPU operations,
the three models and GUI worker startup; they do not establish segmentation accuracy on every dataset.
See the validation record for coverage and limits. Code license: GPL-3.0; third-party notices retained.
